# Data Cleaning: Outlier Detection and Handling Techniques

Data cleaning mein **outliers** wo extreme data points hotay hain jo baqi distribution se bohot alag hotay hain. Outliers ko detect aur handle karne ka mukammal tareeqah neeche tafseel se diya gaya hai.

---

## 1. Outliers Detect Kaise Karte Hain?

Outliers ko pehchan'ne ke liye statistical aur visual methods istemal kiye jaate hain.

### A. Statistical Methods

#### 1. Interquartile Range (IQR) Method
Ye skew dataset ke liye sab se behtar method hai.
* $IQR = Q_3 - Q_1$ calculate karen (jahan $Q_1$ 25th percentile hai aur $Q_3$ 75th percentile).
* **Lower Bound:** $Q_1 - 1.5 \times IQR$
* **Upper Bound:** $Q_3 + 1.5 \times IQR$
* Jo value Lower Bound se chhoti ya Upper Bound se bari ho, wo **outlier** hoti hai.

#### 2. Z-Score Method
Ye normally distributed (Bell curve) data ke liye use hota hai.
* **Formula:** $Z = \frac{X - \mu}{\sigma}$ (jahan $\mu$ mean hai aur $\sigma$ standard deviation).
* Agar Z-score $> 3$ ya $< -3$ ho, toh wo value outlier count hoti hai.

### B. Visual Methods
* **Boxplot:** Box ke bahar jo points/dots nazar aate hain wo outliers hotay hain.
* **Scatter Plot:** Do variables ke darmiyan relationship mein jo points door akele pare hon.
* **Histogram:** Distribution ke bilkul kinaron par alag pare hue bars.

---

## 2. Outliers ko Handle Karne Ke 4 Main Methods

| Method | Kab Istemal Karen? | Kaise Kaam Karta Hai? |
| :--- | :--- | :--- |
| **Trimming / Dropping** | Jab outlier ghalat data entry ho ya bohot kam ho | Outlier waali rows ko dataset se remove kar diya jaata hai. |
| **Capping (Winsorization)** | Jab dataset chhota ho aur data drop na karna ho | Extreme values ko Upper ya Lower bound ki limit par cap kar diya jaata hai. |
| **Imputation** | Jab outlier missing/corrupted value ho | Outlier ko **Median** ya **Mode** se replace kar diya jaata hai. |
| **Transformation** | Jab data highly skewed ho | Log transformation ($\log(X)$) ya Square root transformation se extreme values ko scale down kiya jaata hai. |

---

## 3. Python Implementation Code Example

Sample dataset par **Python (Pandas & NumPy)** ka istemal karte hue 4ron outlier handling methods ka complete code:

```python
import pandas as pd
import numpy as np

# 1. Sample Dataset Create Karna
data = {'Salary': [25000, 28000, 30000, 32000, 31000, 29000, 27000, 33000, 35000, 150000, 200000, 5000]}
df = pd.DataFrame(data)

# 2. IQR Bounds Calculate Karna
Q1 = df['Salary'].quantile(0.25)   # 27,750
Q3 = df['Salary'].quantile(0.75)   # 33,500
IQR = Q3 - Q1                      # 5,750

lower_bound = Q1 - 1.5 * IQR       # 19,125.0
upper_bound = Q3 + 1.5 * IQR       # 42,125.0

print(f"Lower Bound: {lower_bound}, Upper Bound: {upper_bound}")

# --- METHOD 1: TRIMMING ---
df_trimmed = df[(df['Salary'] >= lower_bound) & (df['Salary'] <= upper_bound)]
print("\n1. Trimming Result:")
print(df_trimmed['Salary'].values)

# --- METHOD 2: CAPPING (WINSORIZATION) ---
df_capped = df.copy()
df_capped['Salary'] = np.where(
    df_capped['Salary'] > upper_bound, upper_bound,
    np.where(df_capped['Salary'] < lower_bound, lower_bound, df_capped['Salary'])
)
print("\n2. Capping Result:")
print(df_capped['Salary'].values)

# --- METHOD 3: IMPUTATION ---
median_val = df['Salary'].median() # 30,500
df_imputed = df.copy()
is_outlier = (df_imputed['Salary'] < lower_bound) | (df_imputed['Salary'] > upper_bound)
df_imputed.loc[is_outlier, 'Salary'] = median_val
print("\n3. Imputation Result (Median):")
print(df_imputed['Salary'].values)

# --- METHOD 4: LOG TRANSFORMATION ---
df_transformed = df.copy()
df_transformed['Salary_Log'] = np.log(df_transformed['Salary'])
print("\n4. Log Transformation Result:")
print(df_transformed[['Salary', 'Salary_Log']])
```
